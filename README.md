# MS Chartered Engineers, Valuers & Technical Consultancy Services

A modern, high-performance **MERN Stack** (MongoDB/Express/React/Node.js) web application for **MS Chartered Engineers, Valuers & Technical Consultancy Services**, headed by **Mukesh Singh, CEng (India) MIE, B.Tech (Mechanical) IIT Roorkee**.

---

## 🌟 Key Highlights & Features

1. **Prestigious Brand Presentation**:
   - Complete 7-page company portfolio translated into modern digital UI.
   - Credentials showcase: Institution of Engineers (India) Corporate Member, Chartered Engineer (India), IIT Roorkee heritage.
   - Statutory validity across Banks, Customs, DGFT, NBFCs, and Courts.

2. **6 Core Services Catalog**:
   - **01 Engineering Certification**: Machinery nexus, second-hand import/export certificates, DGFT & customs endorsements.
   - **02 Valuation Services**: Fair market valuation, Remaining Useful Life (RUL) assessment, bank hypothecation & balance sheet audits.
   - **03 Project Consultancy & DPR**: Bankable Detailed Project Reports, financial feasibility, and EPR advisory.
   - **04 Structural & Industrial Services**: Factory structural stability, industrial warehouse inspections, and plant capacity audits.
   - **05 Energy & Environmental Services**: CEIG approvals for Solar power projects, Electrical SLD stamping, rainwater harvesting.
   - **06 Regulatory & Business Support**: EPCG / Advance License certification, statutory filings, and technology advisory.

3. **Smart Engineering Calculators**:
   - **Machinery & Asset Valuation Tool**: Computes Remaining Useful Life (RUL), straight-line (SLM) & written-down value (WDV) depreciation, and fair market range.
   - **CEIG Solar & Statutory Clearance Guide**: Automatic compliance classification (Low Voltage, Medium C&I, High Voltage MW Scale) and required drawing clearances.

4. **Client Consultation & Lead Generation**:
   - 3-Step Interactive Quote Wizard generating Reference IDs with 1-click WhatsApp connect.
   - Instant WhatsApp quick button (`+91 91586 58885`).

5. **Security & Lead Management Portal**:
   - Password-protected Admin Gate (`ms@admin2026`).
   - Live lead tracking with status progression (`New` → `In Review` → `Quoted` → `Completed`).
   - One-click client Call/WhatsApp/Email triggers and CSV Export.

## 🛠️ Tech Stack

- **Frontend**: React 18, Vite, Lucide React, Custom CSS Design System (Glassmorphism, Dark Industrial Theme).
- **Backend**: Node.js, Express.js REST API.
- **Data Persistence**: Dual storage engine (MongoDB via Mongoose + local persistent JSON fallback store in `server/data/inquiries.json`).

## 🚀 Getting Started Locally

### Prerequisites
- Node.js (v18 or higher)
- npm (v9 or higher)

### Installation
```bash
# 1. Clone repository
git clone https://github.com/MINTU325/mscharteredengineer.git
cd mscharteredengineer

# 2. Install dependencies
npm install --prefix server
npm install --prefix client
```

### Running the Application
```bash
# Start unified application on port 5000:
npm start
```
Then visit **`http://localhost:5000`** in your browser.
